# People — example (fictional)

Copy this file outside the repo (e.g. `~/meetings/PEOPLE.md`), fill in your
own colleagues and `export R2R_PEOPLE=~/meetings/PEOPLE.md`. The real file holds
names and roles of real people: never commit it. `.gitignore` blocks the usual
names (`PEOPLE.md`, `people.md`, `*.people.md`, `people.local.*`).

Keys: `zoom` (display name as Zoom shows it), `en` (English spelling), `gender`
(m / f / ? — drives Hebrew verb agreement; `?` = write neutrally), `aka`
(nicknames and the ASR's usual misspellings, comma-separated), `team`, `role`,
`works on`, `notes`.
